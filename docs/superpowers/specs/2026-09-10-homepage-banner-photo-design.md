# 首页横幅合影设计

## 目标

将用户提供的研究组合影作为首页图片轮播的第一张，同时保留现有三张图片与既有轮播交互。

## 方案

- 将原始照片等比例缩放到约 2000 像素宽，保存为 `assets/media/hero-group-2026.jpg`。
- 保持照片接近原始 16:9 构图，不改变人物内容；清除 EXIF、GPS 等附加元数据。
- 在 `content/_index.md` 的 `image.slides` 首位加入新图片，替代 `image.filename` 成为首页首次显示的横幅图。
- 使用替代文本 `中国科大 AGI 研究组 2026 年团队合影`，保留原有三张轮播图及当前轮播组件、样式和自动切换逻辑。

## 验证

- 在 `scripts/verify-site-quality.mjs` 中增加新图片文件、首图顺序、替代文本和四张轮播图的精确断言。
- 先运行校验并确认因新资源尚未加入而失败，再添加图片及首页配置并确认校验通过。
- 使用 GitHub Pages 工作流对应的 Hugo Extended 0.125.7 完成生产构建，检查生成首页包含新图片与替代文本。
- 推送后比较本地 `HEAD`、`origin/main` 与远端 `main` 的 SHA，并确认工作区干净。
